Prompt 2 : Write a Python function that takes a number and returns True if it is even.
Response 2 : Here's a simple Python function that checks if a number is even:
  def is_even(number):
      """Check if a number is even."""
      return number % 2 == 0


  **How it works:**
  - The function takes one parameter called `number`.
  - It uses the modulo operator (`%`) to divide the number by 2.
  - If there's no remainder (i.e., `% 2 == 0`), the number is even, so it returns `True`.
  - Otherwise, it returns `False`.

  **Example usage:**
  print(is_even(4))  # Output: True
  print(is_even(7))  # Output: False
